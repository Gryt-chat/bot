# @gryt/bot

Write Gryt bots in TypeScript.

A bot joins a Gryt server the way any other client does — a key it holds, a
self-signed certificate, and a challenge-response over P-256. From the server's
side it is a member like any other, so what it may do is what its role says.

The SDK itself arrives in the first pull request against this branch.
