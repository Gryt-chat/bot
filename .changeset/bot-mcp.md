`gryt-mcp`: an MCP server, so an AI assistant like Claude Code can read and act on your Gryt servers as a bot. It knocks like any bot, and you approve it in Server settings → Bots and untick what it shouldn't do. It reads channels, threads, search and the member list. With `view_diagnostics` it reads voice rooms, latency and SFU numbers too. It can post, start threads and delete its own messages, and MCP clients ask you before each of those.
